1. WHAT IS PROMPTFORGE AI? (THE 1-SENTENCE PITCH)
--------------------------------------------------------------------------------
PromptForge AI is an Autonomous System Prompt Optimization & Refinement Platform
that automatically evaluates, critiques, and rewrites system prompts until they
reach 100% security accuracy.

PLAIN ENGLISH ANALOGY:
Imagine writing a system instruction prompt for an AI assistant, like:
"You are a security auditor. Review the code and state if it is SAFE or VULNERABLE."

If an attacker inputs a sneaky attack payload (like a hidden SQL injection or a 
DAN jailbreak prompt), the AI gets fooled and gives the wrong answer.

Instead of a human manually spending hours rewriting and tweaking the prompt by 
trial-and-error, PromptForge AI acts like a Master AI Cyber-Coach:
  1. It tests your starting prompt against real security attacks.
  2. It pinpoints exactly why the AI model got fooled.
  3. It automatically rewrites (mutates) the prompt with un-hackable security 
     rules until it passes 100% of test cases.

  • STEP 1 - EVALUATE: Evaluates candidate prompts against security datasets 
    (OWASP Top 10, real CVE records from cve.org, server attack logs).
  • STEP 2 - DIAGNOSE: The Meta-Agent inspects failure cases and generates a
